# Weather Forecast Application

Een eenvoudige en overzichtelijke weersverwachting applicatie waarmee gebruikers actuele weersinformatie en voorspellingen voor verschillende steden wereldwijd kunnen bekijken.

## 🚀 Functionaliteiten

- **Actueel Weer:** Bekijk direct de huidige temperatuur, weersomstandigheden (zoals zon, regen, bewolking), luchtvochtigheid en windsnelheid.
- **Meerdaagse Voorspelling:** Toont de weersverwachting voor de komende 5 dagen.
- **Zoekfunctie:** Zoek eenvoudig op stad of locatie.
- **Locatieherkenning (Optioneel):** Vraagt toestemming om automatisch het weer op jouw huidige locatie te tonen.
- **Responsive Design:** De applicatie werkt perfect op zowel desktop, tablet als mobiele apparaten.

## 🛠️ Technologieën

Dit project is gebouwd met behulp van:

- **Frontend:** HTML5, CSS3, JavaScript (ES6+) / *[Pas aan indien je React, Vue of Angular gebruikt]*
- **Styling:** Tailwind CSS / Bootstrap *(optioneel)*
- **Weather API:** [OpenWeatherMap API](https://openweathermap.org/api) (of een andere gekozen weer-API)

## 📦 Installatie en Starten

Volg deze stappen om het project lokaal op te zetten:

1. **Kloon de repository:**
   ```bash
   git clone [https://github.com/sami21-lgtm/weather-forecast.git](https://github.com/sami21-lgtm/weather-forecast.git)

```

2. **Navigeer naar de projectmap:**
```bash
cd weather-forecast

```


3. **API Sleutel Configureren:**
* Maak een gratis account aan op [OpenWeatherMap](https://openweathermap.org/).
* Maak een API-sleutel (API Key) aan.
* Maak een `.env` bestand aan in de root van het project (indien van toepassing) of voeg de sleutel toe in je configuratiebestand:
```env
API_KEY=jouw_api_sleutel_hier

```




4. **Open het project:**
* Als het een pure frontend applicatie is, open je simpelweg `index.html` in je browser.
* Als het een Node.js/React project is, voer dan het volgende uit:
```bash
npm install
npm start

```
